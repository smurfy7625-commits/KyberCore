# Kyber Core Bug Fix Summary - 2026-09-28

## Login/session persistence

The login flow previously depended on restart-sensitive session state. Kyber now uses a persistent signing secret stored at `/app/config/auth_session_secret`, while the administrator record remains at `/app/config/auth.json`.

Normal container restarts should therefore preserve valid signed sessions as long as the persistent `/app/config` volume is retained.

Authentication hardening includes PBKDF2-SHA256 password hashing, random salts, 600,000 iterations, HttpOnly cookies, configurable cookie security, protected API routes, logout handling, and failed-login throttling.

## Kyber stopping during automatic updates

A bulk update flow could stop Kyber Core while Kyber itself was orchestrating the update. The process could then terminate before Kyber was recreated.

The observed exit was a clean exit rather than an out-of-memory kill.

The fix is to treat `kyber-core` as protected during generic bulk stop/remove/recreate operations and update Kyber itself last from the host.

## Update detection

Update-check work improved stale cache handling, image/digest comparison, refresh behavior, update job state, and Kyber identification. Kyber can be recognized by the `kyber-core` container name or an image containing `kybercore`.

## Container Backups - Stage 1

Validated behavior includes per-container backups, container configuration capture, mapped `/config` data, a safety backup before restore, controlled restart after restore, and exclusion of unrelated media/general-storage trees.

## GPU status

GPU reporting was hardened so dashboard health does not fail simply because NVIDIA tooling is unavailable inside the Kyber container.

## OMV integration

Kyber Core remains OpenMediaVault-specific and uses the host bridge socket at `/run/kyber-omv/bridge.sock`.

## UI/integration fixes

Additional fixes include startup splash configuration/failsafe behavior, cached theme/logo/favicon handling, Docker/Compose/storage startup checks, Seerr integration handling, top-toolbar cleanup, and application-store ordering.
